📌 What is Maantra?

Maantra is a unified AI assistant that operates seamlessly across multiple messaging platforms. Instead of using different bots on different platforms, you get one intelligent assistant that:

🧠 Shared Memory

Your AI learns from conversations on all platforms and remembers preferences across Slack, WhatsApp, Telegram, and more.

🔄 Unified Identity

Link your accounts across platforms so the bot recognizes you everywhere and maintains context seamlessly.

⚙️ Smart Tools

Execute actions, search knowledge bases, summarize threads, and integrate with external services from any platform.

🌍 Multi-Platform

Use your preferred communication channel. The experience is consistent whether you're on Slack, WhatsApp, or Telegram.

Slack Setup Guide

💬

Step-by-Step Slack Integration

Primary Platform

📋 Prerequisites

  • Access to a Slack workspace (admin privileges recommended)
  • Maantra bot application already created in your workspace
  • Bot token with proper permissions
  • Socket Mode enabled for real-time events
1 Create a Slack App (if not already created)

Go to Slack App Dashboard → Click "Create New App" → Choose "From scratch"

Fill in:

  • App Name: Maantra
  • Workspace: Select your workspace

Click "Create App"

2 Configure OAuth & Permissions

In your app settings, navigate to "OAuth & Permissions"

Add these Bot Token Scopes:

Scope Purpose
chat:write Send messages to channels
chat:write.public Send to public channels
channels:read Read channel information
users:read Read user information
im:read Read direct messages
channels:history Read message history
files:read Read uploaded files
3 Enable Socket Mode

Go to "Socket Mode" in the sidebar → Click "Enable Socket Mode"

Generate an App-Level Token:

  • Token Name: maantra-app
  • Scopes needed: connections:write, authorizations:read

Copy this token and save it securely - you'll need it later

4 Subscribe to Events

Go to "Event Subscriptions" → Enable Events

Subscribe to these Bot Events:

  • message.channels - Messages in channels
  • message.im - Direct messages
  • message.groups - Private channel messages
  • app_mention - When bot is mentioned
✓ Save Changes after adding event subscriptions
5 Get Your Tokens

From the "OAuth & Permissions" page, copy:

Bot User OAuth Token
xoxb-xxxx...

From "Socket Mode" page, copy:

App-Level Token
xapp-xxxx...
6 Install Maantra in Your Workspace

Go to "Install App" → Click "Install to Workspace"

Review permissions and click "Allow"

The bot is now installed in your workspace!
7 Configure Maantra Environment

Create or update your .env file in the Maantra project root:

.env Configuration
# Slack Configuration SLACK_BOT_TOKEN=xoxb-xxxx... SLACK_APP_TOKEN=xapp-xxxx... SLACK_ENABLED=true # Other Platform Configs (covered below) WHATSAPP_ENABLED=false TELEGRAM_ENABLED=false
8 Start the Maantra Bot

In your terminal, navigate to the Maantra project directory and run:

Start Bot
uv run python -m src.main
You should see: Bolt app is running!
9 Test in Slack

1. Go to any Slack channel where the bot is a member

2. Send a message: hello maantra

3. Wait for the bot to respond

4. Check the terminal for debug logs (STEP 0-6)

Note: If you see "Sorry, something went wrong" but terminal shows STEP logs, the code is working - likely an API key issue.
✅ Slack Setup Complete! Your bot is now ready to receive and respond to messages in Slack.

WhatsApp Setup Guide

📱

Integrate Maantra with WhatsApp Business

Optional Platform
⚠️ Important: WhatsApp requires business verification and uses the official WhatsApp Business API. We'll use Twilio as the provider for easier setup.

📋 Prerequisites

  • Twilio account with WhatsApp capability (Sign up here)
  • A verified WhatsApp Business Account
  • WhatsApp Business phone number
  • Webhook URL (your Maantra server's public domain)
1 Create a Twilio Account & Get WhatsApp Sandbox

Visit Twilio Console → Create a free account

Under "Messaging" → "Try it Out" → "WhatsApp"

You'll get a sandbox phone number to test with

Sandbox Number Example
+1-XXX-XXX-XXXX
2 Connect Your Number to Sandbox

Send a WhatsApp message to your sandbox number with code: join [YOUR_CODE]

You'll receive a confirmation message in WhatsApp

✓ Your personal number is now linked to the sandbox
3 Get Twilio Credentials

In Twilio Console, go to "Settings" → "Account"

Copy your:

  • Account SID
  • Auth Token

For WhatsApp, get your WhatsApp Phone Number SID from the WhatsApp section

4 Set Up Webhook (Ngrok for Development)

For development, use Ngrok to expose your local server:

Install and Run Ngrok
# Install ngrok (if not already installed) # Download from: https://ngrok.com/download # Start ngrok tunnel (runs on default port 5000) ngrok http 5000

Ngrok will show you a public URL like https://xxxx-xx-xxx-xxx-xx.ngrok.io

5 Configure Webhook in Twilio

In Twilio Console → "Messaging" → "Settings" → "WhatsApp Sandbox Settings"

Set:

  • When a message comes in: https://your-ngrok-url.ngrok.io/webhook/whatsapp
  • Disable all other webhooks (status callbacks not needed initially)

Click "Save"

6 Update Maantra Configuration

Add WhatsApp configuration to your .env file:

.env - WhatsApp Settings
# WhatsApp Configuration WHATSAPP_ENABLED=true TWILIO_ACCOUNT_SID=ACxxxx... TWILIO_AUTH_TOKEN=xxxx... TWILIO_WHATSAPP_PHONE_SID=WAxxxx... WHATSAPP_WEBHOOK_URL=https://your-ngrok-url.ngrok.io/webhook/whatsapp
7 Ensure Webhook Handler Exists

Maantra needs a WhatsApp handler in src/channels/whatsapp/handler.py

This should:

  • Receive webhook requests from Twilio
  • Validate webhook signatures
  • Process incoming messages
  • Send responses back via Twilio API
If the handler doesn't exist, refer to the Slack handler as a template.
8 Restart Maantra and Test

Restart the bot:

Restart
uv run python -m src.main

Send a test message to your sandbox WhatsApp number

Check terminal logs for processing steps (STEP 0-6)

9 Production Setup (Optional)

When ready for production:

  1. Upgrade Twilio account (move from sandbox)
  2. Register your WhatsApp Business Account with Meta
  3. Apply for business verification
  4. Get approved message templates
  5. Update Maantra config with production credentials
  6. Deploy Maantra to a production server with a valid domain
⚠️ Production Note: WhatsApp has strict compliance requirements. Ensure you follow their business messaging guidelines.
✅ WhatsApp Setup Complete! Your bot can now receive and send WhatsApp messages.

Telegram Setup Guide

✈️

Integrate Maantra with Telegram

Optional Platform
ℹ️ Note: Telegram offers the easiest setup among messaging platforms. No approval process needed!

📋 Prerequisites

  • Telegram account (personal account)
  • Access to @BotFather bot in Telegram
  • Webhook URL or polling setup
1 Create a Telegram Bot via BotFather

Open Telegram and search for @BotFather

Send: /newbot

Follow the prompts:

  • Name: Maantra
  • Username: maantra_bot (must be unique)

BotFather will send you a bot token. Save it!

Your Bot Token
123456789:ABCdEfGhIjKlMnOpQrStUvWxYz...
2 Choose Webhook or Polling

Option A: Polling (Easiest for development)

  • Bot continuously asks Telegram for new messages
  • No public URL needed
  • Slower response time (~1-2 seconds)
  • Best for development and testing

Option B: Webhook (Best for production)

  • Telegram sends messages to your server immediately
  • Requires public HTTPS URL
  • Faster response time (<1 second)
  • Best for production

→ We'll use Polling for development

3 Configure Polling (Development)

Add Telegram configuration to your .env file:

.env - Telegram Settings (Polling)
# Telegram Configuration TELEGRAM_ENABLED=true TELEGRAM_BOT_TOKEN=123456789:ABCdEfGh... TELEGRAM_USE_WEBHOOK=false TELEGRAM_POLLING_TIMEOUT=30
4 Configure Webhook (Production)

If using webhook in production:

Set up Ngrok first (same as WhatsApp):

Ngrok Setup
ngrok http 5000

Add webhook config to .env:

.env - Telegram Webhook
# Telegram Configuration TELEGRAM_ENABLED=true TELEGRAM_BOT_TOKEN=123456789:ABCdEfGh... TELEGRAM_USE_WEBHOOK=true TELEGRAM_WEBHOOK_URL=https://your-ngrok-url.ngrok.io/webhook/telegram TELEGRAM_WEBHOOK_PORT=5000
5 Test Bot Commands

In Telegram, go to your bot and try:

Test Commands
/start /help hello maantra what can you do?

Check terminal logs (STEP 0-6)

6 Configure Bot Commands (Optional)

Back in BotFather, send: /setcommands

Select your bot and add commands:

Bot Commands
start - Start using Maantra help - Show help menu summarize - Summarize a conversation ask - Ask a question
7 Join a Telegram Group (Optional)

Create a Telegram group and add your bot

The bot will now:

  • Listen to messages in the group
  • Respond to mentions: @maantra_bot what is 2+2?
  • Remember group context
Note: Bot cannot see messages sent before it joined the group
8 Restart Maantra and Test

Restart the bot:

Restart
uv run python -m src.main

Send test messages to your Telegram bot

Verify terminal shows STEP logs

9 Handle Rate Limits

Telegram has rate limits:

  • Per-user limit: 1 message per second
  • Global limit: 30 messages per second

Maantra automatically handles these with a rate limiter. No additional config needed!

How Account Linking Works

Response Example

Send Linking Code

You'll receive confirmation on both platforms:

"✅ Your accounts are now linked! Your memory, preferences, and context will be shared across all platforms."

From now on:

  • Bot remembers you across Slack, Telegram, WhatsApp, etc.

View Links
show my links

Unlink Account

Debugging Terminal Logs

Expected log pattern for successful message:

STEP 0: Message event received === STEP 1: Raw event extracted | user=U..., channel=C..., text=... STEP 2: Processing channel message without explicit mention STEP 3: Beginning agent processing STEP 4: CALLING AGENT with message: '...' STEP 4: AGENT RETURNED | response.content=... STEP 5: SENDING RESPONSE TO SLACK STEP 6: SUCCESSFULLY SENT TO SLACK ✅

If it stops at STEP 3 or earlier: Message processing issue

If it stops at STEP 4: Agent/LLM issue

If it stops at STEP 5: Slack API issue

Troubleshooting Guide

❌ Bot doesn't respond at all

Check:

1. Is the bot running? (Terminal should show "Bolt app is running!")

2. Are the API tokens correct in .env file?

3. Is the bot invited to the channel where you're testing?

4. Check logs for any error messages starting with [ERROR]

Fix: Restart the bot with fresh credentials

❌ Bot responds with "Sorry, something went wrong"

Check terminal logs for the error:

If logs show STEP 0-6 but still error:

→ LLM API key issue (OpenAI, etc.)

If logs stop at STEP 4:

→ Agent processing error - check agent.py

Fix: Check .env for API keys, restart bot

❌ Slack bot says "not a member of this channel"

Fix: Manually invite bot to channel

1. Open channel

2. Click channel name → Members → Add members

3. Search for "Maantra" and add it

❌ WhatsApp/Telegram messages not processing

For WhatsApp:

- Verify ngrok tunnel is running and URL is correct

- Check webhook URL in Twilio settings matches ngrok URL

For Telegram:

- Verify TELEGRAM_BOT_TOKEN is correct

- Check bot is not blocked in Telegram

Fix: Verify webhook/polling is enabled and check .env settings

❌ Account linking fails

Check:

1. Is code still valid? (expires in 5 minutes)

2. Did you type the code correctly?

3. Are both accounts from different platforms?

Fix: Request a new linking code and resend

❌ Memory not persisting

Check:

1. Is the database file exists? (data/maantra.db)

2. Check MEMORY_ENABLED in .env is set to true

3. Restart bot and try again

Fix: Enable memory in settings and restart bot

❌ Port already in use (webhook setup)

Error: "Address already in use: 0.0.0.0:5000"

Fix Options:

1. Kill existing process on port 5000

lsof -i :5000 | grep LISTEN | awk '{print $2}' | xargs kill -9

2. Or change port in .env: WEBHOOK_PORT=5001

❌ High latency / Slow responses

Check:

1. Is LLM API responding slowly? (check API status page)

2. Is memory search taking too long?

3. Are you rate limited?

Fix: Check API key quota, reduce number of loaded tools, enable caching

Frequently Asked Questions

❓ Do I need to set up all three platforms?
No! You can use just one platform (Slack is recommended for starting). You can add other platforms later. In .env, set SLACK_ENABLED=true and others to false.
❓ Is my data secure when linked across platforms?
Yes. All communication happens over encrypted HTTPS. Data is stored securely in the database. You can view, modify, or delete your data anytime. Unlink accounts at any time to stop sharing memory.
❓ What if I forget to enable Socket Mode in Slack?
The bot won't work! You must enable Socket Mode and use the App-Level Token. The bot uses Socket Mode for real-time events, not webhooks.
❓ Why does WhatsApp need Twilio?
WhatsApp only provides APIs through official business channels. Twilio is one of the approved providers. Alternatively, you can use Meta's Cloud API directly, but it requires more setup and business verification.
❓ Can I use Telegram polling in production?
Not recommended. Polling adds 1-2 second latency per message. For production, use webhooks which are instant. However, polling works fine for testing and low-traffic scenarios.
❓ How long does it take to set up?
Slack only: 15-20 minutes
Slack + Telegram: 25-30 minutes
All three platforms: 45-60 minutes (WhatsApp requires more steps)
❓ What if the bot stops responding?
First, check if it's still running (you should see "Bolt app is running!" in terminal). If not, restart it: uv run python -m src.main. Check .env for correct tokens and API keys.
❓ How do I update the bot without losing settings?
All settings are in .env and the database, not in code. You can safely update code without losing configuration. Just restart the bot after updates.
❓ Can I run multiple instances of Maantra?
Yes! The architecture supports horizontal scaling. All instances share the same database and settings. Each platform adapter can run independently.
❓ What happens if an API key expires?
The bot will show "Sorry, something went wrong" errors. Update the expired API key in .env and restart the bot. No memory or data is lost.
